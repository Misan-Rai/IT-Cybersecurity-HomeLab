# IT & Cybersecurity Home Lab

## About This Project

I'm building my own home lab to gain practical experience in IT support, networking, system administration and cybersecurity.

I'm using equipment I already own to create a small IT environment where I can experiment with different operating systems, manage servers, configure networks and troubleshoot problems.

I'll be documenting what I build, how I configure it, any problems I run into and what I learn along the way.

## Planned Projects

### 1. Ubuntu Home Server
Repurpose my old HP Pavilion laptop into a Linux server, configure SSH and run services using Docker.

### 2. Networking and Segmentation
Learn subnetting, VLANs, routing and firewall rules using Cisco Packet Tracer and isolated virtual networks.

### 3. Windows Server and Active Directory
Build a small Windows domain to practise user management, permissions, Group Policy and troubleshooting.

### 4. Docker and Pi-hole
Deploy containerised services and learn more about DNS, network filtering and server management.

### 5. Cybersecurity and Monitoring
Build on my previous honeypot experiments and explore logging, monitoring and security analysis in an isolated environment.

### 6. Automation
Learn how to automate routine administration tasks using scripts and configuration tools.
